# 🛋️ Mueblería Torres

Sistema web desarrollado con Django para la gestión y visualización de productos de una mueblería y colchonería.

🌐 Sitio web: https://www.muebleriatorres.com/

---

# 📌 Características

- Catálogo dinámico de productos
- Categorías organizadas
- Filtros de búsqueda
- Sistema de stock
- Panel administrador Django
- Integración con WhatsApp
- Productos relacionados
- Sección de ofertas
- Diseño responsive
- Optimización visual moderna

---

# 🛠️ Tecnologías utilizadas

- Python
- Django
- Bootstrap 5
- HTML5
- CSS3
- JavaScript
- SQLite3
- Git & GitHub

# ⚙️ Instalación local

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/pedrinio10/muebleria-web.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd muebleria-web
```

---

## 3️⃣ Crear entorno virtual

```bash
python -m venv venv
```

---

## 4️⃣ Activar entorno virtual

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

---

## 5️⃣ Instalar dependencias

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Ejecutar servidor

```bash
python manage.py runserver
```
